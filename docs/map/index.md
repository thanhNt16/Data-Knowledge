# 🗺️ Knowledge Map

> **Why it matters** — A reference site answers "what is X?". A path answers "what should I learn next?". This map is the curriculum as one journey: sections in learning order, your quiz progress lighting the way.

<KnowledgeMap />

## How states work

- **✅ Done** — you answered ≥ half that chapter's quiz questions correctly (progress is stored locally in your browser, from the quizzes in each chapter)
- **🔵 In progress** — you've started answering but not cleared half
- **⚪ New** — not started yet; nothing is locked, this is a reference — jump anywhere
- Progress resets per chapter via the ↺ button on that chapter's quiz

## Suggested first pass

1. **Visual Intuitions** — build the mental movies first
2. One fundamentals chapter, then follow the map top to bottom
3. Finish each section's quiz before moving on — the map updates instantly
